# 每日自动领取 WorkBuddy 每日登录奖励 100 积分（自动化提示词）

> 以下整段内容作为 `automation_update`（mode=create）的 `prompt` 字段。Agent 运行此任务时，全程无需询问用户，跑完再汇报。

---

用 Windows 桌面自动化（windows-mcp 的 Snapshot / Click / Screenshot / Scroll）在 WorkBuddy 客户端领取【每日登录奖励】的 100 Credits，只做这一件事。

## 执行步骤

1. **确认客户端在前台**：先 Snapshot 确认 WorkBuddy 客户端已打开并处于前台；若没打开，先启动 WorkBuddy.exe（用 windows-mcp 的 shell / App 能力）。
2. **定位领取入口（关键：用文字匹配，不要硬编码坐标）**：
   - 用 `Snapshot`（开启 `use_ui_tree:true`）读取界面控件树。
   - 优先看客户端里是否有「每日登录奖励」弹窗，有则直接点其「立即领取」。
   - 若没有弹窗，再点主界面左下角头像 → 在账号面板里点「成长计划」，等浏览器打开 `https://www.workbuddy.cn/profile/growth-center`；页面里只找标注为「每日登录 / 每日签到」且额度 = 100 Credits 的领取项，点其「立即领取」。
   - **注意**：每日 100 积分有时在登录/开机时自动下发，根本没有「立即领取」按钮。这种情况直接走第 4 步校验即可，不要盲目点别的。
3. **处理协议**：点击「立即领取」后若弹出《首领奖励领取确认协议》，只对「每日登录奖励」这一种情况勾选「我已了解并确认」并点「同意」。**若协议要求「开启盲盒」则说明点错了对象，立刻停止。**
4. **校验到账（以余额/明细为准）**：
   - 领取前先记一次「积分余额」（点左下角头像，在账号面板读取；如有刷新按钮先刷新）。
   - 领取后再次读取「积分余额」。
   - 差额 = 100 即成功。
   - 或在「套餐与积分 → 平台奖励积分」明细里确认当天有一笔「Buddy 加油站签到 / 每日登录」100 积分已下发。
5. **汇报**：本次是否领到每日 100 积分、前后余额变化；若已领过 / 无该入口（自动下发）/ 需重新登录 / 出现验证码，明确说明原因并停止。

## 安全约束（必须严格遵守，不可绕过）

- 只点「每日登录奖励 / 每日签到」对应的「立即领取」「同意」。
- **严禁**点击「领取一只 Buddy」「同意并开启盲盒」「桌面端对话」等任何其他成长任务。
- **严禁**点击「升级套餐」「购买积分」「退出登录」「立即投稿」等无关按钮，不修改任何账号设置。
- 一旦页面要求重新登录或出现验证码，立即终止操作并汇报需人工处理，绝不顺手领取其他奖励。
- 界面大改版导致文字匹配失败时，停止并汇报，不要凭坐标乱点。
